# Roadmap

- Operational backup scheduling, recovery objectives and managed-database deployment drills
  (PostgreSQL persistence, migrations and a synthetic CI restore drill are implemented).
- Federated authentication, tenant membership and role-based review controls.
- Web UI for workbook import, focus-question routing, overlay editing and gap closure.
- Expert-labelled applicability and false-coverage evaluation sets.
- Reviewer confirmation for extracted enterprise-policy interpretations.
- Private-model semantic candidate provider with structured, verified citations.
- CSV/PDF reporting and independently verifiable audit exports.
- Behavioural-testing/evidence integrations, without bundling a separate scanner.
- Regulatory-change impact analysis and version migration.

No timeline or legal-review completion is implied. Open an issue with a concrete
use case or synthetic test fixture to help prioritise the work.
