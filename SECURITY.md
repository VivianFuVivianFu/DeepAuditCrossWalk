# Security policy

This is an experimental MVP. Do not submit live bank policies, customer data or
credentials to a public demo. Review the deployment boundaries in
[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) before self-hosting.

Report security issues using GitHub's private vulnerability reporting feature
when enabled on this repository. If it is unavailable, contact the maintainer
privately through their GitHub profile before sharing exploit details. Never
include secrets, private policies or personal data in a public issue.

Only the current development branch is maintained; no enterprise support SLA
or independent penetration-test claim is provided. Priority concerns include
false confirmed coverage, cross-tenant access, spoofed reviewer decisions,
untrusted document processing and secret exposure.
